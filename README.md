# SACC-App (Sneaker Archive Command Center)

## Version Milestones

### **v1.1-stable** 
* **Details:** Working Python scripts running on Streamlit that incorporate manual path inputs and the Master Location Legend search/renaming logic.
* **Status:** The modern drag-and-drop ingestion (Drop Zone) is currently non-functional for external drives due to Streamlit memory caching limitations.

### **v2.0-path-integration** (Active Development)
* **Objective:** Pivot away from the failing Drag-and-Drop system and integrate a robust File Picker / Path Input field.
* **Goal:** Enable the user to natively paste direct paths or open a system folder-select window to pass absolute paths straight to the Vibe Renamer and Compression engines operating on external M4 drives.
